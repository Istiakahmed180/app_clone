## 4. The two engine-side fixes that unblocked it
#  a) IActivityManagerProxy$GetContentProvider: Google-authority providers are resolved
#     container-first, so microG's com.google.android.gms.microg.settings/.profile are visible.
#     Measured: "authority=com.google.android.gms.microg.settings containerProvider=true"
#  b) ContentProviderStub: on a framework attribution-source UID mismatch, retry once with the
#     calling uid the framework named.
#     Measured: "UID mismatch; retrying query with source uid 10002" then no null cursor.
