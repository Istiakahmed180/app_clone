## 4. What this needed, and what it does not fix
# - The MCS connection only opens when its service is started; microG does not do that on its
#   own. launchProfile now starts it on every clone launch because the connection dies with
#   the guest process.
# - An FCM v1 token is "<instanceId>:<APA91...>" — dropping the prefix returns a 404 from the
#   API (measured).
